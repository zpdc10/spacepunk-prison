# All commands

Every player command on the server. Aliases are in brackets.

## Station and travel

| Command | What it does |
| --- | --- |
| `/hub` (`/spawn`, `/station`) | Back to the station concourse |
| `/warps` (`/shuttle`) | Open the Shuttle Board |
| `/warp <id>` | Travel to a warp |
| `/guide [chapter]` (`/help`, `/tutorial`) | The Station Guide: every system explained in game |
| `/guide bar`, `/guide tips` | Hide or show the checklist bar, turn first-visit briefings off or on |
| `/guide skip`, `/guide restart <chapter>` | Drop the current checklist, or run a chapter's checklist again |
| `/resourcepack` (`/rp`) | Re-send the station texture pack |
| `/hud` (`/sidebar`) | Hide or show your sidebar |
| `/balance` (`/bal`) | Show your Credits, Tokens and Shards |

## Mining and progression

| Command | What it does |
| --- | --- |
| `/mine [id or grade]` | Go to your best mine, or a specific one |
| `/mines` | List the mines |
| `/rankup` (`/ru`) | Buy your next grade |
| `/grades` (`/ranks`) | List grades and costs |
| `/prestige`, `/prestige confirm` | Prestige at grade 25 |
| `/sell` (`/sellall`) | Sell your cargo hold |
| `/cargo` (`/hold`, `/backpack`, `/bp`) | Open your cargo hold |
| `/autosell` | Install or toggle the Auto-Seller |
| `/drill` (`/pickaxe`, `/pick`) | Open the drill bay |
| `/salvage` | Relic collections and decoding blueprints into module schematics |

## Quests and parkour

| Command | What it does |
| --- | --- |
| `/quests [story/tutorials/contracts/track]` (`/quest`, `/q`, `/questlog`) | Open your quest log |
| `/contracts` (`/contract`) | Daily and weekly contracts |
| `/parkour` (`/pk`, `/runs`) | Maintenance runs menu |
| `/parkour go <mine>` | Go to a mine's run |
| `/parkour cp` | Back to your last checkpoint |
| `/parkour leave` | Quit a run |

## Fishing

| Command | What it does |
| --- | --- |
| `/waters [pool]` (`/pools`) | Travel to the fishing pools |
| `/fish` (`/fishing`) | Fish Market, bait, collections, leaderboards |
| `/rod` | Get your rod back, or open the rod bay |

## Workshop

| Command | What it does |
| --- | --- |
| `/workshop` (`/ws`, `/bay`, `/hullbay`) | Go to your hull bay |
| `/ws menu` | Open the workshop menu |
| `/ws open`, `/ws close` | Open your bay to visitors, or close it |
| `/ws crew add/remove <player>` | Share building and machines with a player |

## Trading and gangs

| Command | What it does |
| --- | --- |
| `/ah` (`/auction`, `/blackmarket`, `/bm`) | Browse the Black Market |
| `/ah sell <price> [hours]` | List the held item at a fixed price |
| `/ah auction <start bid> [hours]` | Auction the held item |
| `/ah mine` | Your listings |
| `/ah claims` | Collect purchases, unsold items and proceeds |
| `/trade <player>` (`/tr`) | Ask a player to trade items and Credits |
| `/trade accept/deny <player>` | Answer a trade request (or click it in chat) |
| `/trade history` | Your last 10 trades |
| `/trade locks` | Your prestige trade locks |
| `/trade toggle` | Turn trade requests off or on |
| `/gang` (`/crew`, `/gangs`) | Crew terminal |
| `/gc <message>` (`/crewchat`) | Crew chat |
| `/gang chat` | Toggle crew chat mode |

## Undercroft and guns

| Command | What it does |
| --- | --- |
| `/undercroft` (`/uc`) | Go to the Guard Checkpoint |
| `/undercroft leave` | Leave from the checkpoint |
| `/fence` | Sell contraband (outside the Undercroft) |
| `/gunsmith` (`/guns`) | Buy guns and ammo |
| `/gun` | How guns work |
