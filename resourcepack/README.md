# Spacepunk server resource pack

Everything under this folder is generated by `tools/resourcepack/generate.py` (procedural, original pixel
art, seeded so it is stable). Do not hand-edit the PNGs or JSON: change the generator and re-run it.

```
pip install pillow
python3 tools/resourcepack/generate.py   # rewrites resourcepack/assets, pack.mcmeta, pack.png
python3 tools/resourcepack/validate.py   # what CI runs: JSON, asset keys, models, textures, animations
```

## How it ships

1. `./gradlew build` zips this folder reproducibly into `build/resourcepack/spacepunk-pack.zip` (plus a
   `.sha1`) and embeds it in the plugin jar as `pack/spacepunk-pack.zip`.
2. On enable the plugin reads the zip, hashes it, and serves it from a built-in HTTP server
   (`resourcepack.yml`: `http.port`, default 25580).
3. On join every player gets it as a required pack at `http://<address they joined with>:<port>/<sha1>.zip`.
   Set `public-url` for a proxy/CDN or when the join address cannot reach the pack port.
   Declining kicks with a friendly message; `spacepunk.resourcepack.bypass` skips the kick (staff testing).
4. CI attaches `spacepunk-pack.zip` and its `.sha1` to the `latest` release alongside the jar.

Commands: `/resourcepack` (alias `/rp`) re-sends the pack to you; `/resourcepack reload` and
`/resourcepack info` are for admins (`spacepunk.admin`).

## What is in it

- `assets/spacepunk/items/**` item model definitions for every key in `docs/ARCHITECTURE.md`
  (drills, modules, UI icons, currency). Use them through the `minecraft:item_model` component.
- `assets/minecraft/textures/block/**` mine block retextures (slag, hull plating, conduit ore, cryo panels,
  void glass, neutronium), the deck wall/rim/light blocks from `mines.yml`, and `assets/minecraft/textures/item/**` the matching drop items.
- Animated textures: conduit (redstone) ore flicker, neutronium glow, void glass glints, the Prototype
  drill, Military drill indicator, Token and Shard icons.

`pack.mcmeta` declares format 46 (1.21.4, item model definitions) up to 999, so 26.x clients load it without
an incompatibility warning.
